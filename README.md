# 🕹️ Retro Arcade Guide — دليل الأركيد الكلاسيكي

تطبيق ويب (JavaScript بدون أي مكتبات) لشرح ألعاب الأركيد القديمة، واجهة عربية RTL.

## التشغيل
```bash
cd retro-arcade-guide
npm start        # ثم افتح http://localhost:3000
```
لا حاجة لـ `npm install` (لا توجد اعتماديات). تحتاج Node.js فقط.

## الهيكل
```
public/
  index.html            # الصفحة + السبلاش
  css/style.css         # التصميم (ألوان لكل لعبة/قسم)
  js/main.js            # الراوتر والسبلاش
  js/pages.js           # الرئيسية، اللعبة، القسم، صفحة العنصر، الخصوصية، حول
  js/ui.js              # مكوّنات صغيرة
  js/store.js           # تحميل البيانات + الصور
  data/games.json       # سجل كل الألعاب (بطاقات الرئيسية)
  data/games/<id>/data.json   # كل معلومات اللعبة
```

## الصفحات
الرئيسية ← لعبة ← (الأبطال / الأسلحة أو الحركات / المراحل / الأعداء / القصة / معلومات إضافية / طريقة اللعب وأين تجدها / أسرار) ← صفحة مستقلة لكل عنصر.
ملاحظة: الروابط في `links` داخل كل عنصر تنقل إلى عناصر أخرى (مثلاً من بطل إلى مرحلته).

## الصور
كل عنصر يقبل:
- `"image": "https://…"` رابط صورة مباشر (له الأولوية).
- `"wiki": "Page_Title"` اسم صفحة ويكيبيديا الإنجليزية، فيجلب التطبيق صورتها وقت التشغيل.
وإن فشل الاثنان تظهر أيقونة emoji ملونة بدلاً من الصورة.

## الصور الحقيقية (مهم)
الصور لا تُكتب يدوياً؛ شغّل السكربت **مرة واحدة** على جهاز عليه إنترنت، وهو يحمّل الصور إلى `public/images/` ويكتب مساراتها في كل `data.json`، فيعمل التطبيق بعدها بدون إنترنت:
```bash
npm run fetch-images                 # يملأ الناقص
npm run fetch-images -- --force      # إعادة جلب الكل
npm run fetch-images -- --remote     # روابط ويكيبيديا بدل تحميل الملفات
npm run fetch-images -- --no-gallery # بدون صور احتياطية عامة
npm run fetch-images -- --dry        # تقرير فقط
```
ترتيب المحاولات لكل عنصر: تصحيحاتك في `public/data/images.override.json` ← صفحة `wiki` ← صور مقالة اللعبة المطابقة للاسم ← ويكيميديا كومنز ← بحث ويكيبيديا ← صورة من معرض مقالة اللعبة.
- صور المصدر الأخير (`imageSource` تبدأ بـ `gallery:`) عامة للّعبة (غلاف/لقطة) وليست خاصة بالعنصر.
- لاستبدال أي صورة: أضف في `images.override.json` سطراً مثل `"cadillacs-and-dinosaurs/heroes/jack": "images/jack.png"` (مسار محلي أو رابط). السكربت لا يمحوه.
- التقرير في `tools/image-report.json` يبيّن ما جُلب وما فشل.
- حقوق الصور لأصحابها؛ استعملها لأغراض تعريفية فقط.

## إضافة لعبة جديدة
1. أضف سطراً في `data/games.json` وغيّر `hasGuide` إلى `true`.
2. أنشئ `data/games/<id>/data.json` بنفس بنية الألعاب الثلاث (انسخ أحدها).
3. أقسام `heroes/weapons/stages/enemies/info/howto/secrets` تحتوي `items`، وقسم `story` يحتوي `blocks`. يمكنك تغيير عنوان القسم (مثل «الحركات الخاصة» في ستريت فايتر).

## ما يحتاج مراجعتك
- أسماء مراحل Metal Slug مجمعة حسب البيئة لأنني لم أجد مصدراً موثوقاً لترتيبها.
- أماكن توفر الألعاب قد تتغير: راجع المتاجر الرسمية.
- اكتب بريدك في صفحة الخصوصية قبل النشر.
